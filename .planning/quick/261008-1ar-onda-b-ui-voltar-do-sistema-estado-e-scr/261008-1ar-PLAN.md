## Decisão de plataforma (voltar do sistema) — caminho escolhido e por quê

- **Web/PWA (Safari, Chrome):** só `history.pushState` + `popstate`. O gesto/botão voltar
  do navegador já percorre a history e dispara `popstate`. Nenhum handler de gesto próprio
  na web (duplicaria a subida).
- **Android (Capacitor):** listener `backButton` de `@capacitor/app` (já dependência):
  pilha > 0 → `window.history.back()` (cai no MESMO `popstate`); pilha = 0 →
  `CapApp.exitApp()` (preserva o nativo — registrar o listener desliga o default).
  No iOS esse evento nunca dispara; registrar é inofensivo.
- **iOS (Capacitor/WKWebView):** o gesto de borda nativo do WKWebView
  (`allowsBackForwardNavigationGestures`) é `false` por padrão no Capacitor e o
  `capacitor.config.ts` não expõe chave para ele; habilitar exigiria editar Swift em
  `web/ios/`, que é **gitignored** (`.gitignore:19`) — a mudança não sobreviveria a um clone
  nem a `cap add ios`. Logo: **fallback escolhido = handler de swipe de borda próprio**,
  só quando `isNative && Capacitor.getPlatform() === "ios"`: `touchstart` com
  `clientX <= 20`, `touchend` com Δx > 60 e |Δy| < 40 → se pilha > 0, `window.history.back()`
  (mesmo caminho `popstate`). Ignora toques que começam em `canvas` (gráficos
  lightweight-charts fazem pan horizontal) ou dentro de `[data-sem-gesto-voltar]`.
- **Risco registrado (sem aparelho não dá pra provar):** (a) se `history.back()` em
  entradas `pushState` de mesmo documento dispara `popstate` no WKWebView do Capacitor 8
  (esperado sim — é WebKit padrão — mas não verificado no aparelho); (b) se o swipe de
  borda conflita com algum carrossel horizontal que comece colado à borda esquerda;
  (c) `history.go(-n)` é assíncrono — um toque que empilhe de novo dentro da mesma janela
  de ~1 frame pode dessincronizar a contagem (mitigado pelo contador `ignorarPop`;
  pior caso: um voltar extra sai da sub-tela errada, nunca dado corrompido — é só UI).
  Critério de aceite automatizável = testes puros + estáticos + build; a validação no
  iPhone é o checkpoint humano do Alex no fim do plano 02.

## Modelo de "nível" (fonte única: navStack.js)

`EstadoNav = { tab, carteiraView, perfilView, opcoes: { nivel, temTicker } | null, conceito: { trilha: number } | null }`

- `profundidadeOpcoes(nivel, temTicker)`: hub 0, objetivo 1, escada 2, confirmar 3,
  montar → temTicker ? 2 : 1; qualquer outro valor → 0. (Invariante: para todo estado
  `e` das Opções com profundidade > 0, `profundidadeOpcoes(voltar(e))` = profundidade − 1.)
- `profundidade(e)`: base por aba — `carteira` com `carteiraView !== "main"` → 1;
  `perfil` com `perfilView !== "hub"` → 1; `opcoes` → `profundidadeOpcoes(e.opcoes.nivel, e.opcoes.temTicker)`
  (0 se `e.opcoes` nulo); demais → 0. Soma `e.conceito ? 1 + e.conceito.trilha : 0`
  (cada "‹ voltar" da cadeia de conceitos é um nível).
- `subirNivel(e)` → string de AÇÃO (a função é pura; quem aplica é o App), por prioridade:
  `conceito && trilha > 0` → `"conceitoVoltar"`; `conceito` → `"conceitoFechar"`;
  `tab==="carteira" && carteiraView!=="main"` → `"carteiraMain"`;
  `tab==="perfil" && perfilView!=="hub"` → `"perfilHub"`;
  `tab==="opcoes" && profundidadeOpcoes(...) > 0` → `"opcoesVoltar"`; senão `null`.
- `reconciliarPilha(empurradas, prof)` → `{ tipo: "push", n }` se prof > empurradas;
  `{ tipo: "voltar", n }` se prof < empurradas (n = diferença); senão `{ tipo: "nada", n: 0 }`.
  Entradas negativas/NaN tratadas como 0.
- `chaveDeTela(e)` → `"carteira:historico"`, `"perfil:glossario"`, `"radar"`, `"opcoes"`
  (Opções SEM nível — o wrapper com `key` do plano 02 não pode remontar o OpcoesScreen).
- `chaveDeScroll(e)` → `chaveDeTela(e)` + (`tab==="opcoes"` ? `":" + nivel` : "").
  Para `carteira` com view `main` e `perfil` com `hub`, a chave é só a aba (`"carteira"`, `"perfil"`).
- `transicaoDe(antes, depois)` com `{ tab, prof }`: `antes` nulo → `null`; tab diferente →
  `"tab"`; `depois.prof > antes.prof` → `"entrar"`; `<` → `"voltar"`; igual → `null`.
- `classeDaTransicao(t)` → `"tela-tab" | "tela-entrar" | "tela-voltar" | undefined`.
- `ehGestoVoltarBorda({ x0, y0, x1, y1 })` → `x0 <= BORDA_PX && (x1 - x0) > DX_MIN && Math.abs(y1 - y0) < DY_MAX`;
  exportar `BORDA_PX = 20`, `DX_MIN = 60`, `DY_MAX = 40`. Entradas não numéricas → false.
