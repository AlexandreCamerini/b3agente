## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| conta autenticada → contagem mensal | `metering.month_used(_conn, scope)` lê o kv escopado por `user_id`; nenhum número de uso vem do cliente |
| gate de plano → gate de metering | Precedência explícita e única em `_gate_analise` (contrato C-32): plano decide primeiro, cota física depois |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-10 | Tampering | Cliente forjar a contagem mensal para escapar do cap | mitigate | `used_this_month` é lido no servidor de `metering.month_used`; nenhum campo do body participa. Travado pelo espião do caso (d1), que assere o valor exato recebido pelo gate |
| T-12-11 | Elevation of Privilege | Rota nova de análise chamar `plan.can_analyze` fora de `_gate_analise` e furar a precedência | mitigate | Guardião estático pré-existente `test_plan_can_analyze_aparece_exatamente_uma_vez_no_main` (fase 3, replicado na fase 5) segue ativo e não é tocado por esta fase |
| T-12-12 | Denial of Service | Cap mensal derrubar a rota inteira e deixar o usuário sem NENHUMA leitura do ativo | mitigate | Desenho FIX-C01: a negação vira explicação determinística 200, nunca 502/erro. Travado pelo caso (g) |
| T-12-13 | Repudiation | Recusa por limite ser indistinguível de falha de provedor de IA | mitigate | `iaIndisponivel.code == "quota"` distingue negação por cota/plano de erro de LLM; os casos (a)/(b)/(e) asseram sobre esse campo, não só sobre a mensagem |
| T-12-14 | Information Disclosure | `str(e.detail)` do 402 vazar dado sensível na resposta | accept | O `detail` é a string do hook de `plan.py`, que só contém limite e id do plano — sem chave, host ou PII. O sanitizador T-04-01 já cobre o caminho de erro do LLM |
| T-12-SC | Tampering (supply chain) | instalação de pacote npm/pip/cargo | n/a | Este plano não instala nenhum pacote — adiciona um arquivo de teste e edita um documento. Sem gate de legitimidade aplicável |
