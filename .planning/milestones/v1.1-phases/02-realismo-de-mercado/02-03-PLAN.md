<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provedor de cotação → execução automática | preço externo vira débito/crédito real na carteira simulada, sem nenhum humano no meio |
| scheduler → estado de todos os usuários | um único laço toca a carteira de toda a base |
| kill-switch → fila de ordens | trava operacional que agora represa dinheiro reservado |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-13 | Tampering | preço de execução vindo do lote de cotações | mitigate | o `price_getter` só lê o dict do lote; ticker sem preço numérico `> 0` mantém a ordem pendente com `ultimoErro` (regra vive em `pending_orders`, plano 02-01) |
| T-02-14 | Elevation of Privilege | execução fora do horário de pregão | mitigate | bloco inteiro dentro do gate `not kill_switch_on() and in_market_hours()`; teste assere lista intacta com o gate fechado |
| T-02-15 | Denial of Service | fila grande estourando o orçamento da brapi | mitigate | UMA chamada de lote por passada, com tickers distintos (`sorted(set(...))`); custo O(tickers), não O(ordens) — ADR-008, 15k req/mês para o app inteiro |
