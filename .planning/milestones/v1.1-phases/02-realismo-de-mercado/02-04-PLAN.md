## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| resposta HTTP → estado do cliente | payload do servidor alimenta cash/posições/ordens exibidos |
| store local (iOS) → servidor | o aparelho é local-first e pode divergir do servidor |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-19 | Tampering | `deviceStore` calculando ordem pendente localmente | mitigate | o ramo sem sessão NÃO implementa pendente: levanta erro explícito; motor financeiro fica único no backend (CLAUDE.md princípio 5) |
| T-02-20 | Repudiation | cancelamento reaplicado por fila offline (caixa devolvido duas vezes) | mitigate | `cancelPendingOrder` é chamada direta, fora de `sync.mutate`/outbox, igual a `buy`/`sell`; o servidor ainda responde 404 na segunda tentativa (idempotência de estado, plano 02-01) |
| T-02-21 | Information Disclosure | `marketStatus` carregando dado de conta | mitigate | contrato da rota tem 6 chaves de calendário; nenhum campo de conta é lido pelo cliente |
| T-02-22 | Tampering | assimetria entre stores escondendo estado | mitigate | guardião de paridade por inspeção estática falha se qualquer nome novo aparecer < 2 vezes |
| T-02-SC | Tampering | instalação de pacote npm/pip/cargo | accept | nenhuma dependência nova; `web/package.json` não é tocado neste plano |
</threat_model>
