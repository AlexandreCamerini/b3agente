## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cliente HTTP → rota | request autenticada por Bearer (`current_scope`); `scope=None` é o balde anônimo, e um anônimo só vê as posições do próprio balde |
| rota → provider de cadeia (mydata/Yahoo) | rede externa: orçamento finito (brapi 15k/mês, ADR-008), latência e indisponibilidade |
| motor determinístico → cliente | o payload é a única fonte dos números da tela; nenhum texto de IA atravessa esta rota |
