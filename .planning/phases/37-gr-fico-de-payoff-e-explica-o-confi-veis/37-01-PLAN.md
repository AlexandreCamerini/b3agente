```
def dominio_da_curva(perfil: dict[str, Any], spot: Any = None) -> dict[str, Any]
```

`ganho_ilimitado`, `perda_ilimitada`, `vencimentos: {divergentes}`). Devolve
`{x_min, x_max, y_min, y_max, margem, spot, ganho_ilimitado,
perda_ilimitada, motivo}` — todos snake_case, `spot` já validado/arredondado,
qualquer lado ilimitado devolve `y_min`/`y_max` `None` (nunca inventa teto).

```
def segmentos_da_curva(perfil: dict[str, Any]) -> list[dict[str, Any]]
```
Mesmo `perfil`. Devolve lista ordenada esquerda→direita de
`{de, ate, inclinacao: "positiva"|"negativa"|"zero", e_plato: bool}` — corta
só nos strikes (nunca em breakeven), último item tem `ate: None` (cauda).

Envelope EN de origem (fixture `server/tests/fixtures/mcp_evaluate_petr4.json`,
espelha `evaluate_option_structure`/setups de `propose_option_setups`):
`legs: [{contract, kind: "CALL"|"PUT", side: "buy"|"sell", quantity, strike,
premium, delta, expiration}]`, `max_gain`, `max_loss`, `unlimited_gain`,
`unlimited_loss`, `payoff: [{underlying, result}]`.
