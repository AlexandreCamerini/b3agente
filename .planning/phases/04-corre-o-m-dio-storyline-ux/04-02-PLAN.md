Cria `server/app/benchmark.py`:

  semântica de `yahoo.QuoteUnavailable`.
- `TTL = 900` (15 min) e um cache de módulo `_cache: dict[str, tuple[float, dict]]`
  chaveado pelo `range` resolvido. O orçamento de requisições externas é uma
  restrição real do projeto (ADR-008); a curva de patrimônio é diária e não
  ganha nada com refetch por request.
- `async def serie_ibov(period: str | None = None) -> dict`:
  1. Resolve `rng` com `candles.period_to_range(period)` (mesmo vocabulário de
     período do resto do app).
  2. Cache hit dentro do TTL → devolve a cópia guardada, sem rede.
  3. Miss → `async with httpx.AsyncClient(timeout=20, follow_redirects=True) as client:`
     e `await yahoo._yfetch(client, "/v8/finance/chart/" + SIMBOLO, {"range": rng, "interval": "1d", "includePrePost": "false"})`.
     Reusar `_yfetch` é deliberado: ele já resolve cookie/crumb, rotação de host
     e backoff — reimplementar isso aqui duplicaria a mitigação de 429.
  4. Parse: `result = data["chart"]["result"][0]`; para cada índice com
     `close is not None`, monta `{"date": yahoo._candle_key(ts, "1d", meta.get("gmtoffset")), "close": yahoo._round(close)}`.
     Vela sem `close` é PULADA, nunca preenchida com o fechamento anterior nem
     com 0 (CLAUDE.md item 4).
  5. Recusa granularidade degradada: se `meta.get("dataGranularity")` existe e é
     diferente de `"1d"`, levanta `BenchmarkIndisponivel` — é o mesmo defeito
     silencioso que `yahoo.get_history` já trata (Yahoo devolve HTTP 200 com
     velas mensais).
  6. Série vazia → `BenchmarkIndisponivel`.
  7. Qualquer `yahoo.QuoteUnavailable`, `httpx.HTTPError`, `KeyError`,
     `IndexError`, `TypeError` vira `BenchmarkIndisponivel` com mensagem curta e
     SEM `str(e)` cru do provedor no texto voltado ao usuário.
  8. Sucesso → guarda no cache e devolve o dict do contrato (`t`, `nome`,
     `fonte`, `candles`, `asOf` = data da última vela).
