<interfaces>
Formato que o guardião de espelho consegue ler (web/tests/test_vocabulario_espelho.mjs L101-118):
- bloco `^NOME = \{ ... ^\}` no início da linha; sub-bloco `"educacional": { ... },` e `"operador": { ... },`
- pares `"chave": "valor"` com chave `[a-zA-Z0-9_]+`, valor SEM aspas duplas internas e em UM literal de uma linha só (concatenação implícita "a" "b" quebra o regex). Valor vazio `""` é aceito.
- Rótulos com aspas usam aspas tipográficas: `O “E SE” DO QUE VOCÊ VIU`.
- MODO_JS: educacional ↔ estudo; operador ↔ operador. CHAVE_JS mapeia o dict para a chave em `COPY[modo]`.

Precedente de função de texto: `skill_ref.historico_txt` (L699) ↔ `copy.js historicoTxt` (L2992), `copyFor(mode)` (L2938).
`skill_ref.PUSH_RADAR` (L350-354): chaves `titulo`, `corpo_destaques`, `corpo_vazio`; sem espelho em copy.js.
`skill_ref.num_br(valor)` (L820) formata pt-BR.

Contrato de chamada (consumido por 51-05 no servidor e 51-08 no front):
- Python: `dia_na_bolsa_txt(modo, chave_base, variante, vals) -> str`. `modo` aceita "educacional"|"estudo"|"operador". Se `chave_base` tem variantes (`chave_base_1..N`), usa `chave_base_{(variante % N) + 1}`; senão usa `chave_base` direto. Substitui `{placeholder}` por `vals[placeholder]` (strings já formatadas pelo servidor); placeholder sem valor vira "—" (nunca "0"). Chave inexistente → "" (falha fechada, front não renderiza).
- JS: `diaNaBolsaTxt(mode, chaveBase, variante, vals)` com a MESMA regra, via `copyFor(mode).diaNaBolsa`.
- `dia_na_bolsa_n_variantes(chave_base) -> int` (Python) e `diaNaBolsaNVariantes(chaveBase)` (JS) para o job escolher o índice.
