Incompleto (D-05): put sem contrato na cadeia → resultado.total None, incompleto True, pernasSemCotacao == [id da put], resultado.acoes 500.00, pernasCotadas == −200.00 (só a call), estado "premio_indisponivel", resultado.texto não vazio. spot None → acoes.resultado None, total None, incompleto True, resultado.texto é a frase acao_sem_cotacao.

Estados (ESTR-04; um teste por estado + precedência):
- vencida: vencimentoReferencia < hoje (dias < 0); vence mesmo com perna sem cotação e mesmo ITM
- premio_indisponivel: alguma perna com premioAtual None (vence exercício provável e prazo)
- exercicio_provavel: spot válido e alguma perna não vencida dentro do dinheiro — CALL com spot > strike, PUT com spot < strike (estrito); estadoTexto cita strike e spot; vence ate_5_dias
- ate_5_dias: 0 <= dias <= 5 (dias corridos, mesma convenção de opcoes_lastreadas._dias_ate); dia do vencimento (dias 0) ainda é ate_5_dias
- vigente: demais; nenhum vencimento parseável → vigente com a frase estado_vigente_sem_data e diasParaVencimento None
Eixo aberta_sem_proposta (D-07): pior faixa de liquidez entre as pernas == FAIXA_SEM_MERCADO → abertaSemProposta True, motivoSemProposta "sem_mercado"; senão motivo_sem_proposta informado (ex. "premio_indisponivel") → True com esse motivo; motivoSemPropostaTexto = frase aberta_sem_proposta com {motivo} = opcoes_lastreadas_txt(modo, motivo, ticker=underlying); estado continua calculado independentemente (eixo separado).
Encerrar: vencida → {False, "vencida", texto}; alguma perna com premioAtual None OU sem lastPrice numérico > 0 → {False, "premio_indisponivel", texto citando os ids}; senão {True, None, None}. Cada perna tem o seu `encerrar` pela mesma regra.
Modo: modo "estudo" produz os textos do ramo educacional; "operador" os do operador (teste compara com estrutura_posicao_txt).
Nenhum valor numérico desconhecido é 0.0 (teste varre o payload do caso incompleto: resultado.total is None, não 0).
