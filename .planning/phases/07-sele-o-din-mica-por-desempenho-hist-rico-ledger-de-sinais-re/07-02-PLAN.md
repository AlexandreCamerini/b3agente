<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Ledger (dado medido) → `radarScore` visto pelo usuário | Um número errado no ledger reordena o Radar de 74 ativos para toda a base |
| Escrita no ledger (bootstrap/hook) → leitura por request | Escrita assíncrona/thread separada vs. leitura no pool de threads do FastAPI, mesma conexão SQLite |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Tampering | `registrar_linhas` | mitigate | `UNIQUE(ticker, setup, lado, data_sinal)` + `INSERT OR IGNORE`: reexecução do bootstrap ou sobreposição de cursor não infla `n`, o denominador de toda decisão da fase |
