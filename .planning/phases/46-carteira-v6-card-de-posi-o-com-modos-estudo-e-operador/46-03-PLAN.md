CONTRATO DE SAÍDA (consumido por 46-04 e pela UI; nomes exatos):

`leitura_plano(posicao: dict, preco, compras, modo: str) -> dict`:
{ "ticker", "preco": r2|None, "resultado": r2|None ((preco − avg) × qty), "variacaoPct": r1|None ((preco ÷ avg − 1) × 100),
  "plano": "completo"|"so_stop"|"so_alvo"|"sem_plano",
  "posicaoNoPlano": "abaixo_stop"|"acima_alvo"|"dentro"|None (só com plano completo e preco),
  "distStopPct": r1|None ((stop ÷ preco − 1) × 100), "distAlvoPct": r1|None,
  "rr": r2|None (mesma fórmula de web/src/estruturaCard.js `valorRR`: (alvo − preco) ÷ (preco − stop), só finito e > 0),
  "resultadoNoStop": r2|None ((stop − avg) × qty), "resultadoNoAlvo": r2|None,
  "gatilhoStatus": "valido"|"invalidado"|None (setupEntrada.invalidacao vs preco; lado "baixa" inverte — mesma regra hoje no App.jsx),
  "notaPm": str|None (cartao_posicao_txt "nota_pm" + "nota_pm_vendas" quando Σqty das compras ≠ qty),
  "reguaAria": str|None (só com plano completo),
  "didatica": None | {"paragrafo": [segmento], "borisExplica": str} (só modo educacional) }

`cenarios_da_estrutura(entrada, faixa, nome, spot, vencimento_iso, ticker, modo) -> dict|None`:
None quando faixa None, len(faixa.breakevens) != 1 ou entrada inválida. Senão:
{ "be": r2, "k": r2|None (= faixa.teto), "piso": r2|None, "hoje": r2|None,
  "ateBePct": r1|None ((be ÷ hoje − 1) × 100), "ateKPct": r1|None, "altaForte": r2|None (k × ALTA_FORTE_FATOR),
  "vencimentoTexto": "dd/mm"|None, "faixaAria": str,
  "simulador": None | {"min","max","passo","pontos": [{"preco","resultado","zona"}], "nomeados": {"hoje","equilibrio","teto","alta_forte"}, "zonas": {zona: {"texto","rotulo"}}}  — só modo educacional,
  "payoff": None | {"pontos": [{"preco","resultado"}], "xMin","xMax","yMin","yMax","aria"} — só modo operador,
  "grade": None | [6 × {"chave","rotulo","valor","formato","conta": None|{"formula","numeros"}}] na ordem be, ate_be, ate_k, ganho_max, perda_max, lastro — só modo operador }
formato ∈ "preco"|"pct"|"moeda_sinal"|"qtd". zona ∈ "perda_travada"|"prejuizo"|"ganho"|"ganho_travado".

`didatica_estrutura(nome, faixa, entrada, cenarios, acoes, pernas, ticker, modo) -> dict|None` — None fora do modo educacional. Segmento = {"texto": str} | {"termo": id, "rotulo": str, "kb": kb_id, "noSeuCaso": str}.

`TERMO_KB = {"lastro": "opc-lastro", "call_coberta": "opc-call-coberta", "teto": "opc-teto", "equilibrio": "opc-equilibrio", "piso": "opc-piso", "preco_medio": "mkt-preco-medio", "stop": "stop", "alvo": "alvo", "rr": "risco-rr"}`.
