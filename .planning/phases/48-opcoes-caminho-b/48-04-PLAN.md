  <implementation>
Módulo puro, cabeçalho no padrão de `opcoes_curadoria.py` (sem rede/banco/LLM/relógio; cita Fase 48, 2026-10-05, e as 3 pré-condições acima). Importa só `opcoes_payoff`, `cartao_posicao`, `opcoes_curadoria` (id_candidato, STRIKES_POR_POSICAO), `skill_ref`, `store` (qty_livre).

Constantes: OBJETIVOS = ("proteger","renda","collar"); TIPO_DO_OBJETIVO = {"proteger":"put_protecao","renda":"call_coberta","collar":"collar"}; DEGRAUS = 3; MAX_PONTOS_GRAFICO = 241; LOTE_MINIMO = 100.

Funções:
- objetivos(posicao, modo) — cada item {id, titulo, descricao, perde, disponivel, motivo, termos}; disponibilidade por `store.qty_livre(posicao) >= LOTE_MINIMO`; motivo via opcoes_escada_txt (lastro_travado se qtyTravada>0, senão lastro_insuficiente). Sem posição -> lista com disponivel False e motivo hub_vazio_titulo. `termos` vem da constante de módulo TERMOS_OBJETIVO = {"proteger": [("prêmio","opc_premio",None),("piso",None,"opc-piso"),("put protetora","opc_put_protetora",None)], "renda": [("prêmio","opc_premio",None),("teto",None,"opc-teto"),("venda coberta",None,"opc-call-coberta"),("lastro",None,"opc-lastro")], "collar": [("prêmio","opc_premio",None),("piso",None,"opc-piso"),("teto",None,"opc-teto"),("collar","opc_collar",None)]} serializada como [{rotulo, setor, kb}] — o front só sublinha a 1ª ocorrência de `rotulo` no texto do backend; nunca compõe texto.
- escolher_degraus(candidatos, objetivo, vencimento) — regra acima; índices 0, len//2, len-1 quando len>3; dedupe por idCandidato.
- pernas_do_candidato(cand) -> [{"tipo","lado","strike","premio","contrato"}] (call_coberta: CALL/venda/premioUnitario; put_protecao: PUT/compra; collar: das pernasContratos, optionType call->CALL, put->PUT).
- leitura(pernas, qtd, preco_medio, spot, ticker, objetivo, vencimento_iso, indice, modo) -> dict com: nome (degrau_<objetivo>_<indice>), objetivo, vencimento, vencimentoTexto (DD/MM), strikes {put, call}, qtdAcoes, total{perdaMaxima, ganhoMaximo, premioPago, premioRecebido, liquido}, porAcao{mesmas chaves}, equilibrio, piso, teto, ilimitado{perda, ganho}, colunas (por objetivo, UI-SPEC "Colunas por objetivo": proteger = perda_maxima + custo_protecao; renda = ganho_maximo + premio_recebido + nota sem piso; collar = perda_maxima + ganho_maximo + liquido custa/recebe; cada {chave, rotulo, valor{total,porAcao}, sinal}), fraseRisco, termos {"opc_premio": dados do conceito, "opc_perda_maxima": dados do conceito} (campos exatamente os do allowlist do plano 48-02), grafico|None, motivoSemGrafico, tabela. Monta `entrada_total` (ACAO compra strike 0 premio=preco_medio quantidade=qtd + opções com quantidade=qtd) e `entrada_unit` (quantidade 1) e `entrada_acoes` (só ACAO); perfil por opcoes_payoff; faixa para cenarios_da_estrutura a partir do perfil total; série = pontos do simulador (modo "educacional", só como grade) reamostrados de forma determinística para <= MAX_PONTOS_GRAFICO preservando os preços nomeados; resultado por ponto via resultado_no_vencimento; round 2. Marcadores {n, chave, preco, valor{total,porAcao}}: 1 piso (x=piso, y=resultado no piso), 2 equilíbrio (y=0), 3 teto, 4 perda máxima (x=piso ou xMin), 5 ganho máximo (x=teto); ausentes listados com texto. legenda = [{n, chave, rotulo (marcador_<chave>), setor, kb, valor{total,porAcao}, frase (legenda_<chave>)}] na numeração 1-5 dos marcadores presentes, com setor/kb: piso -> kb "opc-piso"; equilibrio -> kb "opc-equilibrio"; teto -> kb "opc-teto"; perda_maxima -> setor "opc_perda_maxima"; ganho_maximo -> nenhum (null/null). aria {total, porAcao} via grafico_aria. tabela = linhas nos preços nomeados + extremos, ordenadas, sem duplicata.
- degrau_do_candidato(cand, indice, objetivo, posicao, spot, ticker, modo) = leitura(...) + id + execucao (cópia) + liquidez (cópia do bloco do candidato).
- celulas_da_cadeia(puts, calls, spot, posicao, objetivo, vencimento, ticker, modo) — itens do serviço {"contrato","tipo","strike","premio"} (sem bid/ask: por isso NÃO passa por liquidity_score; a peneira de negociabilidade — total_negocios >= OPERAVEIS_MIN_NEGOCIOS — é aplicada pelo CHAMADOR, a rota do plano 48-07, porque este módulo puro não importa options_mcp_api); qtd = (qty_livre // 100) * 100; collar usa a call OTM de menor strike (mesma régua de opcoes_curadoria, selecionados[0]) com cada put; cada célula {indice, nome, id, pernas, total, porAcao, equilibrio, ilimitado, motivo} sem gráfico.
- normalizar_barras(degraus) — muta e devolve.
Nada de "0.0" como ausente; texto só de opcoes_escada_txt; números em texto via skill_ref.num_br/num_br_inteiro.
