## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provedor externo (brapi/Yahoo) → `candle_provider` → payload da API | dado e metadado (inclusive `source`) de terceiro atravessam para a resposta |
| API → cliente web/iOS | `source`/`degradado` viram texto renderizado na UI do usuário final |
| estado de orçamento interno (`brapi_budget`) → payload público | informação operacional do app cruzando para superfície de usuário |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | campo `degradado` em `/api/technicals` (rota de usuário comum) | mitigate | expor SOMENTE o booleano; nunca `gasto`/`limite`/`cotaMes`/`tetoDia`. A copy do usuário final não cita orçamento/cota/limite (contrato do UI-SPEC). Números de orçamento seguem restritos a `/api/obs/usage` sob `require_permission("observabilidade.ver")`. |
| T-03-02 | Tampering | `source` vindo do provedor externo renderizado na UI | mitigate | `FONTE_LABEL` passa valores desconhecidos adiante sem mascarar, mas o React escapa por padrão (texto, não `dangerouslySetInnerHTML`) — nenhuma interpolação em HTML cru é introduzida. |
