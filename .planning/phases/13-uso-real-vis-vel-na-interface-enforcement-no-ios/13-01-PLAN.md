## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cliente (web/iOS) → `GET /api/watchlist/quota` | Bearer token não confiável atravessa aqui; resolve escopo do usuário |
| `watchlist_quota` → `store`/`db` (SQLite kv) | Leitura por `user_id`; vazamento de escopo cruzado seria exposição de dado de outra conta |

Sem token → escopo anônimo (balde `user_id=None`), nunca o de outra conta. Verificado no acceptance criteria da Task 1 |
| T-13-02 | Elevation of Privilege | resolução de plano na rota | mitigate | Usa `_plano_do_escopo(scope)`, que degrada para `ACTIVE_PLAN` (= PLAN_FREE, o MENOS privilegiado) em qualquer falha de leitura do usuário — fail-closed já existente (T-03-13/T-03-14 da Fase 3). Nenhum caminho devolve `limit: None` (sem teto) por erro |
